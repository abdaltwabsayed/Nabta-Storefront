# Nabta — Responsive Plant Shop

A polished, bilingual e-commerce storefront concept built with React, Vite, JavaScript, and CSS. Designed as a freelance portfolio project to demonstrate responsive layout, reusable UI components, filtering, sorting, wishlist interactions, cart state, and Arabic RTL support.

## Run locally

1. Install Node.js (LTS).
2. In this project folder, run:

   ```bash
   npm install
   npm run dev
   ```

3. Open the local URL printed by Vite.

To create a production build:

```bash
npm run build
npm run preview
```

## Features

- Responsive desktop, tablet, and mobile layouts
- English / Arabic language toggle with RTL direction
- Product search and category filters
- Sort by featured, price ascending, or price descending
- Wishlist/favorite toggles
- Interactive shopping bag with quantity changes and subtotal calculation
- Newsletter form validation and success state
- Accessible labels, focus states, and semantic page structure

## Notes

- This is a front-end portfolio demo. Checkout is intentionally not connected to a payment provider or backend.
- Product photographs are loaded from Unsplash URLs and need an internet connection.
- The business name, product catalog, and copy are illustrative. Replace them with your own branding or a real client brief before presenting it as client work.
